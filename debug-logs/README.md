# 调试记录目录

这里存放项目开发过程中的调试记录和问题追踪。

## 目录结构

```
debug-logs/
├── TEMPLATE.md          # 调试记录模板
├── README.md            # 本文件
├── 2026-05-08-xxx.md    # 按日期命名的问题记录
└── archive/             # 已解决问题的归档
```

## 使用方法

### 1. 创建新的调试记录

```bash
# 方法一：使用脚本
./scripts/new-debug.sh "问题简述"

# 方法二：手动创建
cp TEMPLATE.md 2026-05-08-问题简述.md
```

### 2. 填写调试过程

边调试边记录，包括：
- 每次尝试的操作
- 观察到的结果
- 得出的结论

### 3. 解决后归档

```bash
./scripts/archive-debug.sh 2026-05-08-xxx.md
```

## 好处

✅ **知识沉淀** - 解决过的问题不会忘  
✅ **团队共享** - 其他人遇到类似问题可以参考  
✅ **复盘改进** - 定期回顾提升调试效率  
✅ **版本追踪** - Git 记录每次调试的完整历史

## 统计

使用 `./scripts/debug-stats.sh` 查看调试统计：
- 总问题数
- 平均解决时间
- 常见问题类型
